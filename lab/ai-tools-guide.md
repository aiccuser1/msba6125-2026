## DeepSeek 思考模式（必读）

DeepSeek 成本极低（API 价格约为主流模型的十分之一），但**必须开启思考模式（thinking mode）**——未开启时输出明显变差。这是使用 DeepSeek 的第一规则。

### 开启方法

- **网页版**（chat.deepseek.com）：对话输入框上方有「深度思考」开关，点开后再提问
- **API 方式**：请求参数开启思考模式（如 `thinking` 相关参数），未开启时模型返回普通模式结果

### 效果对照（同一 prompt）

Prompt：「总结下面销售数据的主要趋势：1月 120 万、2月 98 万、3月 152 万、4月 143 万、5月 189 万」

| | 思考模式关闭 | 思考模式开启 |
|---|---|---|
| 回答 | 直接给一句话概括：「销售额总体呈上升趋势，其中 2 月最低、5 月最高」 | 先展示推理过程：计算环比（-18.3%、+55.1%、-5.9%、+32.2%），指出 2 月异常下滑需核查促销/季节性，5 月创季度新高，并提示样本只有 5 个月、结论谨慎 |
| 特点 | 快、回答笼统、数字不核对 | 慢一点，但会交叉验证数字、给出有依据的结论、标注不确定性 |

**结论**：使用 DeepSeek时，尽量开启思考模式。多花几秒，换来可核查、有推理链的答案。

## harness：模型之外的另一半（必读）

同样的模型，交给不同的人用，结果可以完全不同。差别不在于模型，而在于**harness（调用框架／agent 外壳）**——你如何包装、调度、约束模型。

### harness 的三个组件

| 组件                       | 含义                             |
| ------------------------ | ------------------------------ |
| 系统提示（system prompt）      | 给模型设定角色、背景、规则的长篇指令（区别于每轮短问题）   |
| 工具循环（tool loop）          | 让模型反复调用工具（查资料、算数、读写文件）直到完成任务   |
| 输出约束（output constraints） | 规定输出格式（表格/JSON/字数/结构），让结果可直接使用 |

### 最小 harness 示例

裸 prompt：

```
总结这份会议记录。
```

加 harness 外壳后：

```
系统提示：你是一位行政助理。总结必须包含三项：决定事项、待办（含负责人与期限）、风险点。用中文输出，不超过 200 字。
```

同一条会议记录，后者输出可直接粘贴进周报——这就是外壳的价值。

## 同任务 prompt 对照

同一任务在不同模型上的用法对照。三个日常任务：改写工作 Email、总结长文、CSV 数据摘要。

### 任务 1：改写工作 Email

- **Gemini**（gemini.google.com）：`你是行政助理，帮我把下面这段草稿改写成正式中文邮件，语气礼貌简洁，分三段，保留要点：<草稿>`
- **Copilot**（Word 内）：选中草稿文字 → 右键「用 Copilot 改写」→ 选「正式/简洁」语气
- **WPS AI**（WPS 文档内）：选中文字 → 「AI 助手」→「润色/改写」
- **DeepSeek**（开启思考模式）：与 Gemini 同 prompt 即可，输出附带改写理由说明

### 任务 2：总结长文（如 10 页报告）

- **Gemini**：把文字粘贴进对话（或上传文档）→ `请用 5 点总结这份报告：核心结论、关键数据、行动建议、风险、遗留问题`
- **Kimi**：长文优先用 Kimi（长文本优势）→ 直接粘贴全文 → 同样 prompt
- **WPS AI**：文档内选中 → 「AI 总结」
- **DeepSeek**（开启思考模式）：同 prompt；思考模式会让它先梳理结构再总结，遗漏更少

### 任务 3：CSV 数据摘要

- **Gemini**：上传 CSV → `请计算各月销售额、环比变化，指出异常值并给出一段管理摘要`
- **Copilot**：Excel 中选中数据 → 「用 Copilot 分析」
- **WPS AI**：WPS 表格中选中数据 → 「AI 分析」
- **DeepSeek**（开启思考模式）：上传 CSV → 同 prompt；思考模式会逐列核对计算

## 知识库问答：NotebookLM 的替代（元宝＋ima）

Google NotebookLM（Gemini 笔记本）能把文档变成可查询的知识库并基于文档作答，但**在澳门与中国无法正常存取**。替代方案是腾讯生态的 **ima 桌面版** 与 **元宝**：

- **ima（ima.copilot，桌面版）**：腾讯 AI 智能工作台——上传 PDF／Word／网页／公众号文章 → 建立个人知识库 → 基于文档问答，**答案附原文出处、可点击核对**；支持知识库共享；免费版 1GB；底层模型混元＋DeepSeek 可切换
- **元宝**：腾讯 AI 助手（混元模型）——主打生产力问答；与 ima 差异化定位（ima 专攻知识库管理）

**操作步骤**：

1. 下载 ima 桌面版（Windows／Mac）→ 手机号或微信登录
2. 新建知识库 → 上传课程讲义／笔记（PDF／Word）
3. 基于知识库提问，答案自带出处；与「把整段文字贴给聊天 AI」相比，回答更集中、可核验

## 常见问题

- **NotebookLM／Gemini 笔记本用不了？** 用 ima 桌面版或元宝替代——上传文档建知识库、基于文档问答（答案带出处），用法见上文「知识库问答」节
- **免费额度受限怎么办？** 稍等几分钟重试，或切换另一个免费模型（本指南对照表内任选）；同一 key 不要并发多个任务
- **Colab 免费额度用完？** 等待额度刷新，或把代码步骤改为本地表格手动完成同一练习（结果应与 notebook 输出一致）
- **数据可以随便贴给 AI 吗？** 不可以。只使用可公开数据与脱敏后的示例数据；公司/客户真实数据不得上传（第 8 课 AI 安全实务会详解）
- **各平台规则会变吗？** 会。本指南以 2026-08 为基准，使用前以各平台官方最新说明为准
