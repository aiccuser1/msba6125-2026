# 第 6 课｜管理者自动仪表板：Excel 档案、资料库与互动式分析

> 本实作由三个核心单元与一个延伸单元组成，情境为虚构咖啡连锁「半岛咖啡」（Peninsula Coffee，共六间门市）：你的角色为分析人员，为管理者建置检视营运的互动式仪表板。单元一为资料理解与指标定义：以 Hermes 读取销售资料（含七张工作表的 Excel 工作簿），盘点资料品质问题，并定义仪表板的关键指标（KPI）。单元二为示范导览与仪表板建置：先开启课程提供的完整示范仪表板，再以 Hermes 生成你自己的仪表板程式并于本机浏览器检视、迭代改良，最后以 Excel 枢纽分析完成人工核对。单元三为资料库化与双来源核对：将资料汇入 SQLite 资料库、以 SQL 回答管理问题，并为仪表板加入 Excel／SQLite 双来源切换，完成「枢纽分析—SQL—仪表板」三方核对。延伸单元（选做，建议在家完成）为以 MCP 连接器（excel-mcp-server）扩充助手直接操作 Excel 的能力。每个单元结束均有检查清单，以供核对完成度。

## 学习目标（Learning Objectives）

完成本实作后，你将具备：

- 以 AI 助手读取多工作表（七表）Excel 资料，说明其栏位结构、规模、时间范围与资料品质问题

- 将资料汇入 SQLite 资料库，以 SQL 回答管理问题
- 为仪表板加入 Excel／SQLite 双来源切换，完成三方核对（枢纽分析—SQL—仪表板）
- （延伸）以 MCP 连接器扩充助手对 Excel 档案之操作能力

### 1.4 资料处理规则（本课共同基准）

资料品质问题必须先决定「如何处理」，各项核对才能进行。若枢纽分析、SQL 与仪表板各用不同口径，数字永远对不上。本课统一规则如下——**之后所有核对（枢纽分析、SQL、仪表板）一律以此为准**：

1. 移除完全重复列（保留第一列）
2. 排除数量极端列（`qty` 大于或等于 100）
3. 门市名称正规化：`北区店` 统一为 `北区门市`
4. 付款方式栏位值去除前后空白
5. 订单中不在商品主档之商品（孤儿商品）保留并标记，但不列入商品与类别排名
6. 空白成本（`unit_cost`）不补值；毛利率仅计有成本之资料列

## 单元二：示范仪表板导览与自建仪表板

### 2.1 概念：管理者仪表板与 Streamlit

管理者仪表板将关键指标集中於单一画面，取代每次手工整并的静态报表。静态报表每次更新均需手工重做；仪表板由程式读取资料档绘制画面——此处「自动」的含义是：程式每次启动或重新整理时重新读取资料档，资料档更新后，画面即呈现最新数字，无需重新制作报表。

仪表板需以可于浏览器检视的互动程式实作；本实作采用 Streamlit——一套以 Python 撰写资料应用的开源框架：单一程式档即可产生含筛选器、图表与表格的网页介面，于本机浏览器执行，毋须部署伺服器。单一程式档之形式亦便于由助手生成与迭代修改。

- Streamlit 官方文件（元件与 API 参考）：官方入口 https://docs.streamlit.io
- 官方安装指引：官方入口 https://docs.streamlit.io/get-started/installation
- Plotly 互动图表（本课图表套件）：官方入口 https://plotly.com/python/

### 2.2 开启示范仪表板（本课最终成品）

课程提供一份完整示范仪表板——这是本课最终成品的样貌。先在浏览器完整浏览一遍，再动手建置你自己的版本。

1. 开启 Windows PowerShell（开始功能表搜寻 PowerShell；不需要管理员模式）
2. 贴上以下第一行并按 Enter；等候安装完成，再贴第二行并按 Enter：

```powershell

& "$HOME\.local\bin\streamlit.exe" run "$HOME\Documents\hermes-sandbox\lab-ch06\demo_dashboard.py"
```

**预期**：第一行显示安装过程，最后出现 `Installed 1 executable: streamlit`；第二行显示 `Local URL: http://localhost:8501`，浏览器自动开启示范仪表板。

- 浏览器未自动开启时：手动开启浏览器，于位址列输入 `http://localhost:8501`
- 此 PowerShell 视窗须保持开启——关闭视窗即停止仪表板；建议保留开启，稍后与你的版本对照

3. 依下表逐页签浏览（侧栏另有资料期间、门市、通路三个筛选器，可随时调整）：

| 页签 | 观察重点 |
|---|---|
| 总览 | 月营收何时最高？2026 与 2025 同期相比增减多少？ |
| 门市 | 哪间门市达标率最低？新开的「路氹城门市」资料涵盖几个月？ |
| 商品 | 营收最高的类别与毛利率最高的类别是否相同？ |
| 时段 | 一天中最繁忙的时段？周末与平日有何差异？ |
| 会员 | 会员与非会员的营收占比？哪个等级贡献最多？ |
| 资料品质 | 六类问题各多少笔？清洗前后营收差多少？——对照你在单元一盘点的问题清单 |

4. 试著将侧栏「资料来源」切换至 `SQLite`：程式会自动把 Excel 资料库化后再读取，两边数字完全相同。这正是单元三你要自己动手完成的事。

## 单元三：资料库化与双来源核对

### 3.1 概念：档案与资料库

Excel 档案适合小规模、单人使用的资料分析；资料库以结构化查询语言（SQL）存取资料，适合多资料表关联、多人并用与权限管理——零售企业的营运系统多以资料库储存交易资料，分析时再汇出为档案。本单元将你的 Excel 资料「资料库化」：汇入 SQLite（Python 内建的轻量资料库引擎，毋须额外安装），以 SQL 回答管理问题；再让仪表板支援双来源切换——同一画面、相同数字，体会「资料层与呈现层分离」：资料存哪里（Excel 或资料库）与画面怎么呈现，是两个可以分开的决定。

- SQLite 官方网站（SQL 语法与文件）：官方入口 https://sqlite.org
- Python sqlite3 模组官方文件：官方入口 https://docs.python.org/3/library/sqlite3.html
- SQL 教学（W3Schools）：https://www.w3schools.com/sql/

## 延伸单元（选做——建议在家完成）：MCP 连接器——excel-mcp-server

### 4.1 概念

MCP（Model Context Protocol）为助手调用外部工具的标准协议。excel-mcp-server 为开源 MCP 伺服器，让助手以工具形式读写 Excel 档案——读取储存格、建立枢纽分析、图表与格式设定；不需要安装 Microsoft Excel。

- 专案与工具清单：官方入口 https://github.com/haris-musa/excel-mcp-server

### 4.2 配置

1. 于档案总管位址列贴上 `%LOCALAPPDATA%\hermes` 后按 Enter；右键 `config.yaml` → 开启方式 → 记事本
2. 按 Ctrl+F 搜索 `mcp_servers`：
   - 已存在：将以下内容新增于该区段之下，缩进层级与既有项目相同
   - 不存在：移至档案最末尾，另起一行贴入整段（`mcp_servers:` 由第一列开始，不可有空格）
   - 将 `<你的用户名>` 换成你的用户名：

```yaml
mcp_servers:
  excel-mcp:
    command: "C:/Users/<你的用户名>/AppData/Local/hermes/bin/uv.exe"
    args: ["tool", "run", "excel-mcp-server", "stdio"]
```

   缩进规定：`excel-mcp:` 前 2 个空格，`command:` 与 `args:` 前 4 个空格。路径中的斜线使用 `/`（不是 `\`）。

3. 记事本选「文件 → 保存」，关闭记事本
4. 回到 Hermes 对话，输入 `/reload-mcp` 并送出
5. 为避免改动原始资料：在档案总管复制 `sales_2026.xlsx` 为 `sales_2026_mcp.xlsx`（点选档案按 Ctrl+C，再按 Ctrl+V；对产生的复本按 F2 改名）
6. 验证——输入（`<你的用户名>` 换成你的用户名）：

```
请用 excel-mcp 工具读取 C:\Users\<你的用户名>\Documents\hermes-sandbox\lab-ch06\sales_2026_mcp.xlsx，回报 orders 工作表的栏位名称与列数。
```

**预期**：助手调用名称以 `mcp_` 开头的工具完成读取，回报栏位名称与 19,967 列。首次调用时自动下载伺服器套件，需等候片刻。

7. 进阶（可选）：请助手以 MCP 工具在复本上新增枢纽分析表：

```
请用 excel-mcp 工具在 sales_2026_mcp.xlsx 新增一张枢纽分析表工作表：以 store 为列标签、revenue 加总为值。
```

**预期**：复本档案出现新工作表；以 Excel 开启复本检视结果。

## 常见问题

| 症状 | 处理 |
|---|---|
| 助手回复无法读取 xlsx（显示 ModuleNotFoundError: openpyxl） | 回复助手：`请安装缺少的套件后重试`；或改用 2.2／2.4 节之 PowerShell 方式启动（安装指令已含 openpyxl 与 plotly） |
| 助手生成程式时显示缺少 plotly | 回复助手：`请安装缺少的套件后重试`；PowerShell 安装指令已含 `--with plotly` |
| 助手启动仪表板后长时间没有回复 | 长时执行指令属正常——直接于浏览器开启对应网址；仍无画面则改用 2.2／2.4 节之 PowerShell 方式 |
| PowerShell 出现 `streamlit` 相关错误且无法启动 | 重新执行 2.2 节第一行安装指令（重复执行会以最新设定重新安装），完成后再执行启动指令 |
| 浏览器显示「无法连线」 | 确认对应的 PowerShell 视窗仍保持开启；确认开启的埠号与启动讯息显示的 `Local URL` 一致 |
| 浏览器未自动开启 | 手动于浏览器位址列输入对应网址（示范 8501／自建 8502） |
| 埠被占用无法启动 | 于指令末尾加上 ` --server.port 8503`（或任一未被占用之埠），并以该埠开启 |
| 修改 `dashboard.py` 后画面未更新 | 于浏览器画面点选 Rerun／Always rerun；或重新整理分页 |
| 示范仪表板如何关闭 | 于其 PowerShell 视窗按 Ctrl+C；或直接关闭该视窗（建议保留开启以便对照） |
| 枢纽数字与核对基准不符（2.6） | 依次检查三项清理：①移除重复列 ②排除 qty≥100 之列 ③北区店已取代为北区门市；完成后应为 19,951 列、11,136,265.52 MOP |
| SQL 查询结果与基准不符（3.3） | 检查 SQL 是否先处理重复列与极端值（提示：`ROW_NUMBER()`／`DISTINCT` 去重、`WHERE qty < 100`）；请助手说明其清洗方式并修正 |
| 双来源切换后数字不一致（3.4） | 将差异贴回对话请助手排查；常见原因：SQL 端未去重、Excel 端未排除极端值 |
| `sales.db` 建置失败（提示档案锁定） | 关闭其他可能开著 `sales.db` 的程式与浏览器分页，重试；或请助手改存新档名后重跑 |
| 找不到 excel-mcp 工具（延伸单元） | ① 对照 4.2 检查缩进（2／4 空格）② 确认 `command:` 路径的 `uv.exe` 确实存在 ③ 再次输入 `/reload-mcp`，或关闭 Hermes 后重启 ④ 首次调用需下载套件，确认网络连线 |
| 助手找到的品质问题不完整 | 使用 1.3 节之追问方式逐项确认；助手若把正常资料判为问题，追问其判断理由 |
| `:free` 模型回应慢或显示 429 | 免费层限速属正常——稍候重试，或更换其他 `:free` 模型 |
